Detector de Celular

Protótipo funcional de detecção em tempo real via webcam, com inferência 100% local.

Problema

Uso do celular ao volante é um fator recorrente em acidentes de trânsito, reduzindo o tempo de reação do condutor — mas validar essa detecção em tempo real exige uma pipeline própria de visão computacional.

O que construí

Pipeline de visão computacional em tempo real com Python, OpenCV e um modelo treinado no Edge Impulse (formato .eim), capturando e processando o vídeo da webcam para inferência local, sem depender de nuvem.

Resultado

Protótipo funcional de detecção em tempo real via webcam, servindo de base técnica para estudos de monitoramento em cabine e assistência ao motorista.

Python OpenCV Edge Impulse Computer Vision

Agente de Triagem de Vagas com IA

Triagem automática de vagas reais a partir de critérios em linguagem natural.

Problema

Buscar vagas remotas alinhadas ao perfil do candidato manualmente é lento e repetitivo, exigindo reler dezenas de anúncios para aplicar critérios simples de nível, stack e modelo de trabalho.

O que construí

Agente conversacional em Python com a API do Gemini (function calling): coleta critérios em linguagem natural, chama uma função para buscar vagas reais no feed RSS do We Work Remotely e outra para registrar a decisão de aplicar ou não em cada vaga, com interface tanto por terminal quanto via Streamlit.

Resultado

Agente que triagem vagas reais automaticamente a partir de critérios em linguagem natural, retornando um resumo com vagas recomendadas e descartadas — sem intervenção manual vaga a vaga.

Python API Gemini Function Calling Streamlit
